# NeuroEvolution Lab

Laboratorio sperimentale per studiare l'evoluzione della struttura delle reti neurali e confrontarla con l'ottimizzazione dei soli pesi.

Il progetto è in preparazione sul branch `experiment/m1-controlled-neuroevolution`. Obiettivo M1: confronto riproducibile, controlli indipendenti, evidenze falsificabili. Nessuna pretesa di dimostrare coscienza o interessi autonomi.
