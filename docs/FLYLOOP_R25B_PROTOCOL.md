# R25B — visual priority, olfactory search
Branch from R25A. No changes to neural weights, motor adapter, physics, environment, or retinal geometry. Five arms: odor, vision, combined (R25A sector-wise max), hard priority, soft priority. Hard: vision if total retinal occupancy > 1e-9, else odor. Soft: alpha=clip(sum(vision)/1.0,0,1), smoothstep alpha=alpha^2*(3-2*alpha); cue=(1-alpha)*odor+alpha*vision. One sector-equivalent (20 degrees) of visible silhouette gives full visual priority; this is a declared design choice, not calibrated biology. No real distance, target coordinates, or bearing in arbitration. No temporal memory, hysteresis or behavior states; odor returns on loss of visibility. Hunger multiplier remains outside fusion.
