# FlyLoop R12 — bounded physical actuator reachability
25 November 2026. Prospective protocol; no R12 outcomes inspected. Parent R11 705d44fad91536cbc5855c998f86feb8ab75a891 remains unchanged.

Question: does the forward-only R9 motor mapping restrict recovery from actual contact? This is an external physical intervention experiment, NOT a learned escape policy or evidence of autonomy.

Fixed design: 24 fresh seeds 12400–12423, both original obstacle and nearfield generators, static geometry. Generate each source trajectory using the original R9 microphysics and frozen R2 recurrent motor controller, up to 160 macros of four microsteps. Collect the first three distinct contact onsets (transition from no contact to contact), without resampling; retain zero-contact seeds and source counts. Snapshot the complete world immediately after each collision. Both actuator plants start from exact deep copies of each source snapshot. No learner, no fast controller, no future information in source generation.

Original plant uses R9 unchanged. Signed plant changes ONLY target speed from V_MAX*sigmoid(1.6*throttle) to V_MAX*throttle (zero command stops in the limit, negative command reverses); same microstep, inertia, heading, collision geometry, injury and energy. This also changes positive throttle calibration, so a supplementary matched-forward signed mapping preserves original positive throttle target for positive commands and uses zero at zero and negative mirrored targets for negative commands. No physical parameters fitted to outcomes.

Exhaustive finite open-loop intervention library: throttle/steer each in {-1,0,1}; all 81 ordered pairs of commands, first held 16 microsteps, second held 16. Identical library per plant and state; terminate on death, otherwise evaluate all 32 steps. Success: four consecutive collision-free microsteps with summed observed displacement >=.035, within 32 steps (R11 criterion). Store each trial outcome, first recovery step or null, distance, contacts, death; store source body and geometry; do not hide failures. State-level reachable means any tested sequence succeeds. Report per seed and geometry, paired state counts, both/original-only/signed-only/neither, and fraction of sequences succeeding. Primary contrast signed linear vs original; secondary matched-forward vs original. Use seed-cluster bootstrap (fixed RNG seed 124001, 5000 draws) on paired per-seed recovery fractions among seeds with contacts. No independent-frame inference. Report coverage and count seeds with contacts.

Prospective screening: at least 12 seeds with contacts overall; paired state reachability increase >=20 percentage points and lower 95% seed-cluster bootstrap bound >0 for primary contrast. Otherwise inconclusive/negative; a finite library cannot prove physical impossibility, and positive result does not establish learned escape. Report all results irrespective of gate. Unit tests: exact original method inheritance, signed positive/zero/negative mapping, identical snapshots and sequences, recovery criterion and death termination, deterministic source and output. Run old R9–R11 regression tests and R12 tests, repeat full campaign byte-identically on CI. No merge or change to previous branches.
