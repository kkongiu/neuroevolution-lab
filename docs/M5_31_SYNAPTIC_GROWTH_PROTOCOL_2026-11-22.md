# M5.31 — FROZEN protocol: experience-shaped synapse consolidation in one predesigned nonlinear neuron

**22 November 2026. Protocol recorded before the full GitHub Actions evaluation.**
This is a development-only structural-plasticity trial, not evidence of an
autonomously invented neuron, open-ended neural evolution, or cognition.

## Hypothesis and actual intervention

M5.30 selected among seven **complete researcher-supplied operators**; it
managed 78.56% unseen accuracy in parity-plus-pairwise-AND tasks but failed
to handle three-way interactions absent from its menu. M5.31 removes the
seven-item discrete operator menu **from the candidate**. It instead trains
four continuous **synaptic input gates** of a single initially soft
conjunction neuron (one gate per sensed bit), plus a scalar correction
strength, along with a five-weight M5.29 product predictor.

The neuron uses the **researcher-predefined conjunction mechanism**:
\`h(x)=product_i [1 - g_i*(1-x_i)]\`, and multiplies the base predictor by
\`1-2*alpha*h(x)\`. Only \`g_i\`, \`alpha\` and base predictor weights
are tuned using the organism's **eight own chosen-action/binary-reward**
experiences. Sixteen float64 random initializations, 300 full-batch
backpropagation steps, deterministic clipping, and a 0.01 alpha penalty
are fixed in the protocol. The eight best soft candidates by support-only
fit yield thresholded synaptic masks (\`g_i >= 0.5\` and
\`alpha >= 0.5\`); only masks with >=2 incoming synapses are eligible.
The selected hard topology must survive a fresh fixed-budget
M5.29 product-network fit on support examples corrected by that topology.
The final choice minimizes **support-only** MSE plus 0.012 per preserved
connection. Zero-connection topology is always allowed. No exam cue or
exam outcome is consulted at any stage.

This is **differentiable candidate synapse learning followed by structural
consolidation / pruning**, not unconstrained de novo invention: the
researcher supplied one conjunction-neuron primitive, a binary-XOR-style
correction interpretation, four candidate input edges, exact thresholds,
optimizer and pruning policy. The controller is independently reinitialized
in each task; no across-lifetime executive weights are learned. All task
contexts A/B/C remain explicitly observable.

## Distinct DEV-only split and controls

Small pilot trials (not a reportable confirmation) previously used seeds
8000–8009, 9000–9009, 10000–10009 and were seen while designing this
protocol. **Those seeds cannot be counted as future independent validation**.
The following *fresh synthetic* cohorts are locked for GitHub Actions:

- Parity only: seeds 11100–11111 (12)
- Parity + one pairwise conjunction: 11200–11215 (16)
- Parity + one triple-input conjunction: 11300–11315 (16)
- Parity + XOR of two disjoint pairwise conjunctions: 11400–11407 (8),
  deliberately outside the representational capacity of one conjunction.

Each seed is assessed under 3 independent optimizer initialization seeds
(881, 883, 887), for **156 seed/model rows** across 52 tasks, each with
three explicitly identified contexts A/B/C = **468 learning contexts**.
Each context sees eight randomly chosen support sensory cues and eight
disjoint unseen cues, using only actual chosen binary actions and observed
success. The support actions are **randomly generated by the test harness**,
not selected by an active-exploration neural policy: this is feedback-based
learning, not a learned autonomous exploration strategy. Complete affine masks 5,9,11,14 are retained from earlier DEV
work; these are exposed task-family masks and are **not** new-family
independent replication. Data generator and intended tests remain
deliberately synthetic.

For the same support observations and unseen exams, report:
1. **Plastic-grown and pruned neuron** from real reward, then hard-mask
   refit and frozen evaluation (candidate).
2. No-growth M5.29 fixed product, trained from actual rewards.
3. Same growth mechanism with **independently scrambled** support rewards;
   grade against real untouched exam truth.
4. Random hard synapse mask (2–3 inputs) with real-reward product refit;
   tests whether selecting edges from feedback matters.
5. Original fixed seven-option **M5.30 operator menu** trained and selected
   on identical support, to compare previously supplied pairs.
6. Human-privileged exact true correction mask, fit with same product
   learner; only an explicitly labeled upper reference for representable
   single-conjunction tasks, never a candidate's input. On two-pair
   out-of-class tasks this reference falls back to no correction.
7. Continuous **unconsolidated** soft neuron, scored as a sign predictor
   without hard pruning, to test effects of hard discretization.

Track selected 4-bit synapse masks, actual learned alpha/gates, number
of surviving synapses, candidate count, frozen scores and full raw rows.
The final compact selected task code is **5 float32 weights (160 bits) +
one 4-bit edge mask = 164 bits per visible context; 492 bits for A/B/C**.
This excludes 16 simultaneously optimized soft networks, up to 8
refits, historical support, gradients, model architecture, selector
logic, temporary compute, and the unreported neural initializations;
it is NOT whole-brain RAM or an energy efficiency claim.

## Prespecified narrow screening gates

The experiment must report each item as pass/fail without retroactive
threshold changes:

1. Pair family candidate unseen accuracy >=70%.
2. Triple family candidate unseen accuracy >=70%.
3. Pair family candidate improvement over fixed product >=8pp.
4. Triple family candidate improvement over M5.30 pair-menu >=5pp.
5. Pair family candidate improvement over scrambled-reward growth >=15pp.
6. At least 20% of pair family contexts consolidate >=2 synapses.
7. Each evaluation task's eight support cues completely disjoint from exam.
8. Candidate fitter receives neither hidden true conjunction, parity
   function, nor exam outcomes (enforced by signature and tests).
9. Persistent final three-code representation exactly 492 bits.
10. Out-of-family two-pair interaction stress reported, even if negative.

Passing implementation invariants is not equal to scientific success.
The development gate is a **narrow screen** only. Even if it passes:
\`autonomously_invented_neural_operator=false\`,
\`shared_meta_plastic_controller_learned=false\`,
\`independent_task_family_replication_complete=false\`,
\`evolution_authorized=false\`,
\`advance_to_evolution=false\`. No mutation/evolution or use of
originally sealed M5.6 ecology; no automatic merge to \`main\`.

A statistically weak or negative outcome must be preserved and reported.
Confidence intervals may be exploratory paired hierarchical bootstraps
over three optimizer seeds and cohort seeds; do not claim general-purpose
statistical certainty, identical compute, or energy efficiency.
