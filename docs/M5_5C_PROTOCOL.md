## Scientific hypothesis and limits

At MAIN 3 predators, 400-tick prey ecology is nontrivially selective: exact clones survived 3/8, sparse 2/9 mutant arms 4/8, random-genotype newborns 5/8 and fear-blind control 0/8. The sparse-vs-clone 20k world-paired bootstrap 95% confidence limits INCLUDED ZERO. We must not call this evidence of beneficial evolution. M5.5C tests whether a genotype **born by a genuine within-world M5.5B sparse mutation**, selected by its actual SOURCE descendants' reproduction, outperforms **its own exact source naive original founder** when frozen and identically transplanted to new independently randomized worlds. The preprogrammed nine-trait instinct scaffolding and one-cell predator physiology are fixed.

## Six frozen genotype interventions per source seed

For every source seed, transplant one **constant frozen genotype to all 20 ORIGINAL-physics naive founders** of a fresh world. All births from those transplanted founders are physically costed exact numeric clones; zero within-transfer mutation. Same motor/reproduction/food physics, same local current enemy detection and fear code, same 3 real predators and original predator movement. Same world seed creates exact identical walls, initial food, food regeneration schedule, 20 initial founder positions and three original enemy start positions for *all six* arms.

1. `mutant_descendant`: exact nine source descendant genes from the actual M5.5B source mutated newborn.
2. `own_original_founder`: exact nine original source founder genes for **that child's own founding family**, no unrelated founder substitution.
3. `full_gene_reversion`: reconstruct mutant descendant with all original founder nine coordinates restored (must be EXACT bitwise same genotype/physical outcome as arm 2; a positive invariant/audit control).
4. `fear_gene_reversion`: mutant descendant genes 0..7 but replace ONLY g8 with its own founder's g8; keeps other accumulated natural mutations.
5. `fear_gene_only`: own original founder genes 0..7 but transplant the descendant's actual mutated g8; tests whether source g8 change alone is responsible for gains or losses.
6. `matched_random_genome`: fixed independently random N(0,.65)^9 genotype from source seed + predeclared tag 55551; sampled exactly ONCE per source family and reused across all its transfer worlds. This is a capacity/unspecified-genotype control, never tuned to test data.

Original native nine-gene reflex action remains identical to M5.5B CLONE for all arms; no frozen action differences by arm except inherited genome. Freeze precise output CSV, success/failure and controls after this prospective registration, no retroactive parameter adjustment.
