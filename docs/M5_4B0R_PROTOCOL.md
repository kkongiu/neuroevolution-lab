# M5.4B0-R — PREREGISTERED 18-gene true-neural-recurrence capacity test

**Frozen BEFORE writing B0-R code or running any B0-R world outcome**, 21 Nov 2026. Background: M5.4A established odor radius5→2 is the dominant driver of numerical-clone extinction; M5.4B0 tested 96 externally selected 10-gene numerical genomes on completely independent worlds, all failed original-radius2 survival, while the separate human-scripted novelty-search reference survived 36/36. [Issue #43](https://github.com/kkongiu/neuroevolution-lab/issues/43).

## Question, inference boundary and architecture

Can exactly eight new **inheritable, bounded REAL RECURRENT NEURAL WEIGHTS** improve representational viability at short odor radius2, compared with the **SAME ten genes with recurrence CLAMPED OFF** and an independently externally optimized original non-recurrent ten-gene scaffold?

- The first **ten numeric genes** remain *exactly* the original M5.3B `m5_3b.to_weights`: four directional input/bias modes, food/odor/wall sensitivity, and reproduction. Never change the meaning of any of those original genes.
- New **genes 10–13**: `self_feedback_i = 0.65*tanh(gene[10+i])`, placed on recurrent connection from previous hidden `i` to current hidden `i` for each i∈0..3. These are learnable/heritable numerical feedback parameters, not a programmed navigation rule.
- New **genes 14–17**: `lateral_feedback_i = 0.35*tanh(gene[14+i])`, placed on recurrent connection from previous hidden `(i+1)%4` to current hidden `i`; exactly one cyclic lateral pathway for each i∈0..3. No other recurrent connections. Total absolute recurrent incoming weight for each hidden directional neuron ≤1.0, bounded memory, hidden activation still original tanh.
- Existing first ten genes are unchanged in all neural arms, except when separate external optimizer finds a different numerical genome. The same eighteen-gene vector **with eight recurrence terms set to zero** must have an expanded 401-weight genome EXACTLY equal to `m5_3b.to_weights(first10)`. Unit tests must require this bit-by-bit, not merely approximated.
- Original `m5_0.network_logits`, `m5_0.act`, original local 15 input sensors including last-failure/last-food, same five action logits (four cardinal moves and reproduce), original true energy, food, age, legal-mask physical laws and 400 ticks. **ALL numerically decided births are unmutated clones** inside any world. Only external researcher search perturbs candidate vectors between independent development trials. **THIS IS NOT ENDOGENOUS EVOLUTION**.
- The original recurrent RNN has hidden state reset to 0 at birth. It is not given global position, food locations, visited-cell lookup table, scripted policy, source-code editing or network/tools/filesystem access. Bounded recurrence can preserve a numerical short-run history but is **not** a guarantee of global mapping or remembering every visited cell.
- Explicitly separate human-SCRIPTED M5.1 greedy+novelty policy for physical viability. Scripted memory/birth preferences are programmer-supplied, never part of numerical genotype.

- **Development worlds 89000–89003** (4), **validation worlds 89100–89107** (8), entirely fresh **MAIN sealed worlds 89200–89223** (24) and **SHIFTED sealed worlds 89300–89311** (12). Zero overlap with historical sealed M5.0–B0 studies; never retune these sealed worlds.
- Development/evaluation world physics uses original independent M5.0 world generator, not M5.4A's common restricted food-support matched sampler. MAIN odor radius2, walls .12, food regeneration .55; SHIFTED odor radius2, walls .20, food regeneration .40; all otherwise original physical defaults (15×15, 20 initial food, food cap32, 20 founders, max64, 400 ticks, max age100). Every world reuses identical original map/initial founder positions, food schedule and actor-order RNG across neural genotype arms. Script reference has different behavior but same physical ecology.
- Two independent **RESEARCHER-CONTROLLED EXTERNAL numerical search** runs of identically fixed budget: one uses 18-gene recurrent map, another uses **original 10-gene fully feedforward** map as matched external-optimization-budget negative architecture. Each has **48 iid N(0,.65) random genomes** and **three generations of 16 researcher-perturbed external candidates** (96 total each), perturb exactly **two randomly selected gene coordinates** by N(0,.22) from cyclic elite parent among prior global top6. Each uses its own fixed RNG: recurrent **89411**, feedforward **89412**, and NEVER uses sealed worlds to select/tune.
- Each candidate assessed on all four **development** worlds for 400 ticks (96×4×2=768 separate world-policy trials). Score lexicographic: number of worlds with population alive at tick400, sum of final living organisms, total food eaten, total physically costed births; lower candidate index for ties. Before every external generation, sort global eligible previous candidates, choose top6; external candidate parent list fixed by score only.
- Select top6 candidate vectors from each architecture using development rank. Each has independent eight-world **validation** (6×8×2=96 world-policy trials). Winner per architecture from (validation survival, validation final populations, validation food eaten, validation native births, development rank, candidate ID) in that order. Freeze full-precision winner recurrent and feedforward vectors before ANY sealed outcomes. **DO NOT compare by looking at heldout 89200+ or 89300+ worlds before selection.**
- Never seed the recurrent or feedforward externally trained winners as allegedly uninformed founders for later genuine within-world evolution.

## Frozen matched sealed trial arms and statistics

Each of **24 MAIN +12 SHIFTED** new worlds tested with exactly **8** arms: 
1. `recurrent_witness`: externally selected 18 genes with real bounded recurrent feedback weights.
2. `recurrence_clamped`: same exact first10 of winner but last eight recurrent terms set to ZERO in neural processor. Differences isolate recurrent channels within selected vector (selection on recurrent performance makes test advantage conditional on externally optimized witness).
3. `feedforward_witness`: separately, independently externally optimized old ten-gene original network of equal external budget, with all recurrence fixed zero.
4. `recurrent_scrambled`: same selected eighteen gene values permuted deterministically with `random.Random(89470)`; no manual selection if permute accidentally equal (abort).
5–6. `random_recurrent_0` and `random_recurrent_1`: TWO fixed independent N(0,.65) eighteen-gene numerical controls, with fixed RNG seeds **89500** and **89501**, no external selection.
7. `random_feedforward_0`: ONE fixed N(0,.65) original ten-gene random numerical control, seed **89502**.
8. `scripted_greedy_novelty`: original separately HUMAN-SCRIPTED local greedy odor+visited-cell novelty and physical reproduction, **NOT** a neural genotype.
Total sealed **(24+12)×8=288** 400-tick trials. Whole campaign **768 development +96 validation +288 heldout =1152 physically costed 400-tick world runs**, and historical unit/smoke CI.

Main survival gate for **numerical representability** (must satisfy EVERY condition): recurrent witness alive at tick400 in **≥12/24 MAIN** worlds; has ≥1 native true birth in ≥12/24 MAIN worlds; has positive paired survival gain over SAME-GENES `recurrence_clamped` (paired 20k world bootstrap **lower 95%>0**); and also positive paired survival gain over **independently externally optimized** `feedforward_witness` with 20k paired world-bootstrap lower95%>0; separate human-scripted viability ≥18/24 MAIN. Recurrent witness alone surviving without beating matched clamp and matched external feedforward is not evidence of benefit from added recurrent degrees of freedom.

- **OOD separate gate**: recurrent witness ≥6/12 SHIFTED survivor worlds, positive paired delta vs clamp and feedforward with bootstrap lower95%>0, regardless of MAIN gate.
- **20,000 deterministic paired-world bootstrap** draws: seed **89601** for MAIN contrasts, **89602** for SHIFTED contrasts; use +1000 per contrast index in fixed arm comparison order clamped, independently optimized feedforward, recurrent scramble, random recurrent0, random recurrent1, random feedforward0. Save both paired per-world deltas and summary CI.
- Full per-world outcomes: survival, final agents, real births, generation, food eaten, reproduction legality corrections, physical energy residual, founder/source genome hash, exact clonal birth hash, and 50-step checkpoints. External source genes and all 768+96 selection-world trials retained permanently, plus 288 final world trial rows, full-precision 18/10 selected genes, four numerical controls and src/seed RNG.
- Report individual main/shifted survivor counts for every arm (not only winner), means food and births, effect direction and 95% descriptive bootstrap bounds, whether these fixed criteria pass/fail. Report no effect from recurrent weights if bootstrap does not support even if winner appears visually better; keep zero/negative results.
- **Cannot infer genuine natural evolutionary adaptation** from an external researcher optimizer even if recurrent witness eventually succeeds. Original M5.4B1 remains a separately preregistered random-founder true birth-mutation and post-shift selected-genotype-vs-exact-founder experiment using totally NEW never-trained, never-heldout worlds and untrained independent random founder genes.
