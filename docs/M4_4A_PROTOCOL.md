# M4.4A — Within-life synaptic plasticity + true recurrent memory: prospective physical T-corridor test

**Frozen 22 Nov 2026 BEFORE implementation, training/validation outcomes, or looking at final data.** This is a *distinct* carefully staged integration study responding to issue #26. Do NOT imply that the later M5.5B/M5.5C predator branch (still not integrated into main) already contains lifelong neural learning. The M4.3 neural hidden-state memory and M3.3 within-life SGD were previously established in separate tasks, but no study established their coupled advantage in the same physical organism.

## Hypotheses, controls, and honest limits

- Can ONE persistent recurrent neural controller, starting with random weights, learn during its simulated life from the *actual energy/food reward resulting from its own physical branch choice*, while the same network's recurrent state retains the earlier cue during a physical corridor traversal? At the end of a training lifetime freeze its weights, and test on never-seen new corridors with matched opposite hidden food target.
- Stage 1 is a physical **scaffolded motor** task, **not autonomous navigation**. The physical robot occupies one grid square, has energy, consumes real movement cost, and is forced by externally scripted forward motion along an M4.2 13×13 rotated/reflected T corridor until the fork. At fork, the neural network alone chooses between two legal physical branch actions, moves there, and either physically eats food (reward +1) or finds none (reward −1). The **wrong branch has 0 food** and never reveals where the other target is. Source food location never enters the observation, loss, or sensors; terminal reward is grounded exclusively in the organism's own physical observed outcome.
- The motor scaffold necessarily leaks that a decision occurs only at the fork; this is researcher's curriculum, not naturally evolved autonomous movement. Each training episode is a new physical corridor traversal with energy reset, hidden activations reset, **same organism's synaptic weights kept across all 288 training episodes**; thus "within simulated learning lifetime" means repeated conditioned episodes, NOT continuous fully autonomous ecological survival. No native M5 food ecology or predators yet; claiming full autonomous behavior or full lifelong adaptation would be incorrect.
- The network is an eight-tanh-hidden, 19 local-observation, four-action *Elman RNN* with EXACT M4.2/M4.3 260 parameter layout. The 11-hidden 268-parameter feedforward matched capacity comparator uses EXACT original FF layout. We implement terminal reward-modulated online policy-gradient **backpropagation-through-time** for the single stochastic fork action and all preceding physical sensory states, not programmer-labeled correct directions and not external genetic evolution. Only feedback is +1 actual food found / −1 none; action/own output probability are available. The same gradient rule updates hidden input weights, recurrent weights, and action readout weights. No global map, episode IDs, world seed, target goal, sign or supervised teacher labels input to any network/policy.
- The network sees a one-hot **absolute correct gate direction** for only the first TWO physically visited cells, identical to original M4.2 cue encoding. This cue is experimentally provided, NOT discovered by the agent. No food odor and no hidden target information is provided later. At fork the last observation for paired opposite target worlds is identically bitwise equal, so correct paired decisions cannot arise without retaining earlier cue. For the causal reset manipulation **same learned RNN weights** but set all recurrent hidden units to zero just before processing the final fork observation. (The fork readout itself may re-activate fixed non-cue features; matched opposite goals rule out retrieval.)
- No genetic reproduction and **no inherited learning** in this experiment. Original full M4.2/M4.3 source is not modified. All ordinary neural controls are the same initial random weight sample per genetic seed. Reader must distinguish synaptic updates over training episodes from hidden-state recurrent updates within each episode.

## Frozen experimental budget and seeds (never changed after seeing results)

- Source and development-only small seeds 120000–120011, not in any final split; debugging tests MUST ONLY use these.
- **Eight** independent initial random genetic/initialization seeds **124000–124007**. Each initializes both RNN and approximately matched-parameter FF architectures independently with std .35, all zero final output biases at initialization, no externally evolved champion selected.
- **Train 24 physical world geometries 121000–121023**, both opposing hidden goal worlds in each geometry, repeated **6 epochs = 288 physically acted, rewarded training episodes per network**. At each epoch shuffle the same 48 episodes with deterministic RNG depending ONLY on neural init seed + epoch; every training arm gets the EXACT same ordered world/target sequence and number of available 288 reward events. The network sees training reward only from its own actual sampled action, never target label.
- **Final frozen independent MAIN worlds 122000–122031 (32 paired geometries)**, with native original stem length 3–5, original native M4.2 cue_ticks=2, original physical movement cost=1, initial energy24 and food energy16, random rotation/reflection, 13×13 blocked physical T, autonomous neural binary gate choice once physically escorted to fork, 64 goal-opposite trials per genetic initialization (8 ×64=512 family-world-goal trials per arm).
- **Final frozen independently unseen HARD/OOD longer-delay worlds 123000–123015 (16 paired geometries)** with original M4.2 shifted stem 5–6, 32 opposite-goal trials per genetic initialization, all else identical; no selection or meta-training on these worlds.
- **Fixed online learning settings:** policy-gradient ascent learning rate `0.045`, clip each full-episode gradient vector by global norm ≤`2.0`, bound individual updated weights to [−4,+4], apply a tiny fixed `1e-5` L2 penalty on weights. Temperature 1.0 softmax over two fork actions. All 288 training updates active in the online arms; no updates in frozen arm. Random training action RNG uses neural init seed+episode index and is independent of food/world seed. Pre-readout terminal reward +1 if actual physical food eaten, otherwise −1. Exactly one optimizer step after **each** physical episode, no online changes while traversing within an episode. No episodic replay buffer or other stateful teacher.
- **Six frozen arms** (same MAIN/OOD evaluation seed+geometry and per-genetic-source initial weights): `online_rnn` standard reward-trained RNN; `initial_rnn` identical untrained original RNN; `online_rnn_reset` trained online RNN with entire 8 hidden states reset before fork decision; `online_rnn_flipcue` same trained online RNN with cue left/right swapped during initial two steps but physical food target **unchanged**; `shuffled_reward_rnn` same RNN trained for exactly 288 episodes using independent random ±1 fake terminal reward as the policy gradient target (actual physical food still measured, only feedback is shuffled) then correctly evaluated; `online_ff` parameter-matched 268-weight feedforward trained with exactly same online gradient, epochs and physical feedback, which can never read the disappeared cue at fork. `scripted_one_bit` explicitly human-programmed positive reference chooses observed initial one-hot cue correctly; `random_binary` untrained chance reference shares paired-world random draw, 50% by construction. The last two are **references** and do not have trained neural capacity; eight arms total.
- The fixed plastic RNN vs reset/flip arms reuse the **same fully trained genome** for strict within-genotype causal ablations. In final tests no arm learns/updates and stochastic sampling is disabled: choose argmax legal at fork; initial full genome, training reward and learned weight SHA256 for each neural arm are frozen before *any* final evaluation.
- Training/TEST geometry, walls, incoming local observations, energy accounting and physical food semantics identical across arms (except shifted length where specified). Reward only after physical gate entry; observed cue at the start of each epoch is turned off well before fork. The physical fork input must hash identically for opposite hidden targets, and all paired worlds must share geometry/food position except invisible reward location.

## Outcomes, inference, stopping rules

- Primary: mean binary **physically collected food** during heldout MAIN paired world/goal decisions per init seed. Differences paired per **eight independently initialized networks** using 20,000 resamples of the eight network seed effects; **world/goal trials nested within each trained network are NOT independent learning replicates**. Fixed bootstrap seed 125001 MAIN, 125002 OOD, +1000 per named comparator. Save signed per-network differences and percentile bootstrap 95%.
- Principal comparisons `online_rnn−initial_rnn`, `online_rnn−shuffled_reward_rnn`, `online_rnn−online_rnn_reset`, `online_rnn−online_rnn_flipcue`, `online_rnn−online_ff` and independent LONG-delay replication of each. Note FF, reset, and initial **can** have nonzero performance over individual worlds but on perfectly balanced paired identical final inputs without cue retention the achievable mean over the pair is 50%. The result of `online_rnn−initial_rnn` may be near zero if randomly initialized recurrence is already useful; treat as null not hidden success.
- Required combined main positive gate: MAIN online RNN ≥0.65 correctness and bootstrap lower95% `online_rnn−initial_rnn` >0, `online_rnn−shuffled_reward_rnn` >0, `online_rnn−online_rnn_reset` >0, AND positive across ≥6 of 8 independent initial networks. A separate stringent generalization gate also requires OOD online RNN ≥0.60 and lower95% online RNN−reset >0; failure must remain visible. Online RNN−FF and flipped cue are essential diagnostics, not additional independent primary proofs. Because the goal pairs and reset make baselines mathematically 50%, neither multiple related contrast bootstraps nor plus-cue flips are independent sources of evidence.
- Secondary: training performance by epoch, original synaptic weight change L2 and hashed pre/post weights, per-module gradient change norms (input/recurrent/readout), proof recurrent weights genuinely move, action reward distribution, rewarded energy, movement count, actual gate arrival 100% with scaffold, no wall collisions, exact old-vs-NEW maze sensor semantics; any failure prohibits reporting a "fully embodied autonomous intelligence" conclusion.
- Paired 20k *cluster* bootstrap 95% is **descriptive**, not significance guarantees; no multiple-testing correction. Keep all negative results.
- **Autonomous transfer diagnostic**: with weights frozen, run the SAME learned RNN genome through original `m4_2.simulate(..., "evolved_rnn", genome)` without guided stem, on 8 **separately reserved 123100–123107** independent physical corridor world pairs, record complete reach-fork, feed, and success. Compare same-genome untrained network. This motor diagnostic is *not* the preregistered recall gate and cannot be used to optimize the main genotype. No claim of continuous autonomous lifelong learning until this succeeds robustly in a separate prospective study.
- Full statistical study includes 8 neural initial seeds × 3 learned neural policy variants ×288 training episodes (= 6,912 training episodes) and 8 × (32+16) ×2 ×8 arms (=6,144 final world-arm evaluations), plus 8×8×2×2=256 autonomous diagnostic physical evaluations; all generated from deterministic original code and committed source-only+final data. If compute is high, preserve results with explicit stop, no retroactive discounting. Frozen source/genetic seeds never selected using final data.
- Before final heldout tests, persist **both** exact initial and 288-update learned weight vectors for all seeds and three learning variants (RNN, RNN shuffled rewards, FF) in a Git committed genotype bank or GitHub Actions archived step, and record its independent SHA. That full original genome bank must be frozen/committed **BEFORE** test worlds. Pre-train tests MAY use 120000-range development worlds; must never use 122000–123015 or 123100–123107 during training/bank selection or smoke checks.
- Finally permanently commit ALL per-world physical outcomes, training curves, network weight-change evidence, per-initialization contrasts and complete preregistered gates. Any source mismatch, energy mismatch, leaked hidden target into policy, unexpected hidden stimulus, or source-bank modification stops execution.

## Interpretation guardrail

Passing tests means **bounded learned synaptic plasticity and recurrent hidden-state memory jointly improve reward-seeking under a scaffolded physical T-corridor curriculum**. It does NOT mean evolved open-world food seeking, self-generated attention, self-constructed memory maps, real-world biological neural plasticity, or independent ecological survival. If negative, report null and diagnose online gradient credit assignment vs representation bottlenecks without retuning heldout outcomes. Only a later independent experiment may integrate online synapses with unguided motor/reproduction/predators.
