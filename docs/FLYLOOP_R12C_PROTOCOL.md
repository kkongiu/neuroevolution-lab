# R12C — bodily sensing
Sensor-only extension of R12, no learning or escape policy. Keep physical integration, costs and geometry unchanged. Original eight channels remain an exact prefix. Add three rear rays, eight body-relative contact sectors (front, positive 45 degrees, positive 90, positive 135, rear, negative 135, negative 90, negative 45), eight consecutive contact durations normalized by 32 microsteps, actual signed displacement velocity, motor target, blocked displacement fraction, actual injury increment normalized by the original nominal per-step injury, and remaining integrity. Contact sectors derive from first intersection of attempted center segment with the ORIGINAL radius-inflated rectangular obstacles or world borders, using entering face normals toward obstacle. Simultaneous face contacts activate multiple sectors. This is collision-face localization in the existing square-inflated geometry, not literal skin pressure or a force model. Signals are last completed microstep only; no prediction or global coordinates exposed to circuits. No persistent localized tissue damage: original injury is scalar. Rear rays are proximity not touch.
Expose optional slow 16-neuron and fast 4-neuron adapters with original weights unchanged and added input weights initialized zero; no automatic motor response. Slow prefix original 8; fast prefix original 7. Additional weights can later be learned in a separately registered experiment. Test physical parity with R12, cardinal/rear contacts, corner ties, no false touch from proximity, duration reset, signed motion, damage and zero-weight network equivalence. Run deterministic regression on GitHub. No claim of learned body schema or scientific motor efficacy.
