# R25A — finite visible food target
Branch from R24C. Ground mechanics only, no light or heat, same metabolic and ingestion rules, same frozen R1 weights and R19D affordance adapter. Food is a non-solid visible disk of radius .25 (body radius .30 plus disk radius matches existing .55 ingestion radius). No contact physics change. Sensor returns fractional angular occupancy in each existing 20-degree forward retinal sector (180 degree field); exact disk silhouette 2 asin(radius/range), clipped to each sector. World geometry is used only inside sensor; no numeric distance, absolute coordinates, or explicit target bearing given to controller. Contrast fixed at 1, ideal continuous sector occupancy, no noise or obstacle occlusion in this free arena. Rear objects are invisible when outside field. No optic flow or temporal visual learning yet.
Compare masked, odor-only (identical to R24C), vision-only, and max(odor,vision) per sector, same hunger scaling and unchanged adapter. This reuses existing cue interface; the recurrent brain still receives original proximity/proprioception/hunger only. It tests sensory integration through the existing innate adapter, not learned visual depth or autonomous braking. Angular occupancy and odor amplitudes differ by design; cannot attribute differences uniquely to size without a fixed-width retinal ablation later.
Distances .8,1.5,3; angles 0,+/-45,+/-90,+/-135,180; starts at rest or .6 units/s, energy 50, horizon 30s or first meal/death. 12 existing seeds 35100..35111 and 12 prospective new seeds 37100..37111, paired, fixed geometry. 24*3*8*2*4=4608 episodes, exact repeat 9216. No tuning. Record retinal vector, odor vector, command, pose, speed, yaw, target distance and bearing for diagnostics only. Primary outcomes meal rate and near-zone misses, time to ingestion among successes, initial .2s forward speed/throttle (short window to avoid early ingestion censoring), approach speed, path distance, rotations and reverse time; stratify by initial distance, angle and speed, cohort. Record mean speed while within 1 unit before ingestion (conditional on visits). Tests: monotonic angular occupancy vs distance, symmetry, field clipping, rear masking, odor-only regression to R24C at distance 3, repeat. Report all conditions, no promotion. Earlier branches remain untouched.
