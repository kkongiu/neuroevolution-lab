# M5.33 — preregistration: does active sensory sampling resolve sparse-interaction ambiguity?

**22 November 2026. Frozen before the M5.33 complete GitHub Actions development run.**

## Question and boundary

M5.32's two learnable conjunction units did NOT learn two independent
interactions reliably from eight random own-action/reward observations:
real reward accuracy **50.52%** vs reward-scrambled 52.08%, with only
8/11 prospective gates passing. M5.33 examines whether **where we
sample the environment** matters, not whether simply adding more
neurons fixes the problem.

The testing harness permits a sensory sampling policy to request a
**4-bit cue** from one of 16 distinct sensory states; the environment
then picks the same precommitted random binary action for that cue in
all arms and reveals ONLY the reward for the actually chosen action.
No policy sees ground-truth function labels or unchosen rewards.
In this deterministic two-action task a failed chosen action
logically implies its complement succeeds; this is a deliberately
strong and fully disclosed binary assumption.

**Crucial distinction:** our most informed active policy uses a
HUMAN-PROGRAMMED candidate class containing the actual generative
families (affine parity × possible 0/pair/triple/two-disjoint-pair
AND residuals), not a learned curiosity executive. It knows the
**possible grammar**, NEVER which concrete target rule is true.
This is an **engineered epistemic planning diagnostic** and could
artificially favour the active arm. Compare with family-blind
input-diversity exploration and a corrupted-feedback planner.
Do NOT call it autonomous learned curiosity, emergent operator
discovery or independent general intelligence.

## Freeze data, seeds, observation budgets

Use a **fresh new task-SEED development cohort**, not any seeds from
M5.31/M5.32 or their pilot design, but use the SAME synthetic
families of functions (thus NOT an independent family replication):
- plain parity: 12100–12107, eight seeds;
- parity + one pairwise AND: 12200–12211, twelve seeds;
- parity + one triple AND: 12300–12311, twelve seeds;
- parity + XOR of two disjoint pairwise ANDs: 12400–12411, twelve seeds.

Each seed has the three **externally observable A/B/C contexts**,
generated by the same M5.31 grammar from a new fixed seed mixing
function. Two independent downstream neural optimization initializations
(1031,1033) yield 44×3×2=**264 paired learner row contexts per
selection arm** across 132 unique task contexts. Every arm uses **the
same initial two sensory cues**, the SAME random action for any given
cue, and exactly **eight distinct cumulative action/reward
observations**, selecting the next six cues sequentially. At each
step select an unvisited cue using ONLY prior observations.

Arms (all 8+8 = 16 total sensory states, no duplicated support cue):
1. **random_cues**: a seeded random permutation, fixed two starting cues.
2. **coverage_only**: greedy maximin Hamming distance from all earlier
   cues, no reward use; fixed seed tie-breaker.
3. **family_version_space_active**: exact posterior filtering of
   HUMAN-DEFINED possible truth tables by own action/reward, then
   request the next cue closest to a 50/50 split among surviving
   hypotheses, with Hamming coverage and a precommitted random
   permutation for deterministic tie-breaking. Exhaustive
   prior hypothesis catalog includes the family truth, but neither
   a target ID nor a truth label is handed to the policy.
4. **scrambled_belief_active**: the identical adaptive version-space
   selector sees independently randomized **false** support rewards
   for planning its next cue, while the neural learner receives
   **authentic** environmental reward for each selected cue. Thus
   the contrast isolates the value of truthful active beliefs rather
   than sabotaging the supervised downstream optimization. If all
   imagined hypotheses are eliminated, reset the *planning only*
   candidate catalog to all hypotheses (report reset counts).

For each acquired eight-cue dataset, separately fit M5.32's same
**dual-soft 15-parameter neural architecture WITHOUT the harmful
diversity penalty**, using exactly 8 starts ×300 SGD steps, identical
optimizer seed, float32 inference, same 4-bit input mapping and
actual chosen action/reward supports. No true target rule, intended
interaction mask, exam outcome or candidate grammar enters this
neural learner; only the ACTIVE SELECTOR is allowed the
researcher-supplied grammar. Matched number of neural parameters,
restarts, updates and feedback observations across ALL four
arms; **selection computation itself is not FLOP/energy matched**
because catalog enumeration is expensive. Record the candidate
catalog size and all stepwise candidate counts as planner cost proxies.

Each arm's unseen complement is its own 8 never-queried cue IDs,
so **unseen-only accuracy exams have unequal cue sets across arms**.
For this reason, the **PRIMARY paired measure is all-16-cue
prediction accuracy**, including eight cues seen in support,
evaluated on the EXACT SAME 16 sensory states for every arm. This is
an **in-sample-inclusive measure** and cannot by itself establish
unseen-cue generalization; always report the **secondary heldout
8-only accuracy** together with its uneven exam-set caveat.
Also measure exact version-space identifiability of the full
16-cue function, posterior candidate count, and Bayesian majority
vote accuracy on 16 cues using the allowed researcher-defined
hypotheses. All post-hoc scoring sees full truth only in the
environmental grading layer.

The remaining 8 cues for every policy are **exam only** and never
update its belief, decisions, neural model or model selection.
Record sensory requests and authentic observed responses for each
arm for a complete selection firewall audit.

## Prospective narrow screening checks

1. Model-informed active planner's mean surviving model count
   at 8 observations is at least **20% lower than random** on
   the two-disjoint-pair cohort.
2. Exact true-function identifiability on two-pair tasks improves
   at least **+10pp** vs random.
3. Neural learner all-16 accuracy on two-pair tasks improves
   at least **+5pp** vs random.
4. Neural learner 8-unseen accuracy on two-pair tasks improves
   at least **+5pp** vs random (acknowledge different exam sets).
5. Active true-belief selection beats scrambled-belief active by
   at least **+5pp** in the *all-16 neural accuracy* two-pair cohort.
6. Active true-belief beats label-free coverage at least **+3pp**
   on the same all-16 neural accuracy measure in two-pair tasks.
7. Active two-pair neural all-16 accuracy reaches **>=60%**.
8. Actual true function survives in all truthful posterior
   hypothesis sets; no oracle truth into the policy or neural fit.
9. Every arm has 2 identical starting cues, then exactly six
   distinct adaptively requested cues, equal randomized precommitted
   chosen action per cue and exactly 8 genuine support rewards.
10. All 16-cue and arm-specific 8 unseen-only evaluation, reward
    scrambling and alternative coverage controls faithfully
    reported with complete raw sensory traces.
11. Two-unit learned inference retains 15 real float32 weights,
    and evolution flags remain all false.

No hidden early stop on a failed metric, no threshold changes.
The science screen is all-or-nothing and **NOT** evolutionary
authorization even if it passes. Exploratory paired task-level
bootstrap intervals must distinguish context/seed correlation.

## Honest limitations and stops

Even positive results would confirm at most **active selection in an
engineered, task-family-aware version space**. An organism autonomously
learning its own curiosity policy, knowing when to ask questions,
generalizing to unknown task grammars, long-term memory or open-ended
synaptic invention is **NOT** tested. Entropy reduction could help
the ideal hypothesis solver without improving the actual gradient
network; preserve that distinction.

No independent task-FAMILY replication. No claim of matched
exploration-compute or economical learning. Sealed original M5.6
ecology unchanged; no merge to main.

Mandatory FALSE flags in report, regardless of gates:
\`learned_general_curiosity_policy\`;
\`autonomously_invented_neural_operator\`;
\`shared_meta_plastic_controller_learned\`;
\`independent_task_family_replication_complete\`;
\`continual_memory_retention_verified\`;
\`evolution_authorized\`;
\`advance_to_evolution\`.
