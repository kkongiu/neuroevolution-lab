# FlyLoop R10 — Slow circuit teaches fast circuit
**25 November 2026. Prospective protocol committed BEFORE implementation and first R10 data.** DRAFT stacked on R9 #99; main and all R1–R9 source unchanged.

## Falsifiable hypothesis
R9 established a physical .05-s fast defensive bypass but independent reward learning made collisions worse. In R10 the **slow system alone experiences consequences, learns an action-outcome critic, and teaches the fast four-neuron student a motor command**; the fast student's supervised learning never consumes bodily injury, contact or reward as a label. Test slow-validated teaching vs indiscriminate imitation, temporally shuffled teaching, a fixed fast circuit, direct R9 physical reward and a slow-only baseline.

The original slow 16-neuron R1 recurrent network stays fixed. A new researcher-defined **slow critic** linked to its actual 16 recurrent activations uses 56 learnable coefficients to predict progress/contact and judge experienced movements. A "good demonstration" is an explicitly specified researcher validation, NOT an independently discovered survival goal. The teacher is not assumed competent; the protocol requires an actual count of eligible good episodes and more effective bodily results, or it FAILS. No programmed left/right escape maneuver, attack stimulus, biological fly behavior, or evolution.

## Six prospective control arms
1. **slow_only:** slow critic trained on actual experienced movements; NO fast motor override or fast teaching.
2. **fast_fixed:** same original initialized four-neuron rapid pathway and fast noise, NO fast teaching.
3. **fast_direct:** original R9 fast output online eligibility rule trained ONLY on directly observed microphysical progress −contact reward AFTER actual execution during t>=120, not from teacher. Never trained before the test. A different training schedule, disclosed.
4. **fast_naive:** during t<120, imitate EVERY completed slow action target even if it collided/was experimental; no direct bodily reward to fast.
5. **fast_teacher:** during t<120, imitate ONLY successful slow-critic-validated nonexploratory true actions from the SAME organism. No direct bodily reward to fast.
6. **fast_shuffled:** same fast teacher validity filter and training schedule but motor target comes from a REAL VALIDATED instruction of the SAME organism at least 8 original macrosteps OLD; otherwise skip update and retain current state. Report effective sample count; this tests state/lesson temporal mismatch, not fictitious physical outcomes.

All six arms share precisely the SAME physically executed t<120 slow episodes for any matched seed/geometry/regime. All real slow teacher labels/critic predictions, whether accepted or rejected, and every fast output update are archived. No fast learner can inspect bodily collision, movement, injury or reward except the special explicitly direct R9 comparison arm (which learns only during t>=120). All teacher motor corrections are researcher-defined and not a spontaneous reflex.
