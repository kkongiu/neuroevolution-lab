# Deterministic environment contract
Every experiment declares environment seed, genetic seed(s), fixed microstep, horizon, resource schedule, intervention parameters and code revision. Use independent local random streams; never consume environmental randomness in response to agent actions. Generate the entire external schedule before simulation; hash its canonical representation. No wall-clock, external services or unordered iteration in simulation. Same environmental schedule for all matched arms; cross environment and genome seeds independently. Log initial conditions, resource births, consumption, capture, mortality and trajectories. Commands computed from a common pre-step snapshot; resolve competition deterministically, with stable IDs only as final exact-tie breaker. Resource generation does not depend on hunger, survival or experimental arm. Occupied spawn slots produce an explicitly logged overflow according to the declared policy; schedule never changes. External food supply and actual available inventory are distinct: the latter can depend on consumption. Use integer ticks, not floating-point time comparisons. Preserve exact repeated outputs on the same runtime and record runtime version; cross-platform bitwise equivalence is not presumed. Report paired results and uncertainty over independent seeds; deterministic does not mean representative. No selection of favorable seeds after results. New models remain experimental until validation and comparisons pass. 
## R22B module
Immutable precomputed food events using fixed integer tick interval, environment-only RNG, valid arena locations with obstacle clearance; finite inventory with one independent portion per event (stacking allowed, no occupancy-dependent respawn). Initial prototype only: integration with R22A is a separate step. Sex metadata and future mutation streams must not affect environment generation.
