Protocol frozen *before* code and evaluation: [docs/M4_0_PROTOCOL.md](../docs/M4_0_PROTOCOL.md). Fixed train worlds 41000–41007, validation worlds 42000–42003, unseen main 43000–43031 and harder shifted 44000–44015. Primary paired food collected evolved vs wall-avoiding random, secondary vs unevolved random neural, strong greedy odor heuristic and no-odor ablation mandatory. All scientific findings including nulls must be preserved without post-hoc tuning. GitHub Actions executes read-only; archives full metrics, saved champion and example world visualization.
